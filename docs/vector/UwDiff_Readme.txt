■ 概要
------------------------------------------------------------------------------
UwDiff は、2 つのファイル（または 2 つのフォルダー）を比べて、どこが違うかを
出すツールです。画面（GUI）とコマンド（uvd）が入っていて、どちらも同じ
比べ方をします。

・形式を問いません。テキスト・ログ・CSV・TSV のほか、圧縮ファイル 7 形式
  （gz・bz2・xz・lzma・zst・lz4・br）は展開しながら中身を、Word・Excel・PDF は
  取り出した文字を比べます。外部のコマンドは要りません。
・文字コードを問いません。UTF-8・Shift-JIS（CP932）・EUC-JP・UTF-16 を
  自動で見分け、旧と新で文字コードが違っても比べられます。
・表（CSV・TSV・Excel）はキー列で照合します。行の順番が違っていても、
  追加・削除・セル単位の変更を出します。
・採る変更だけを選んで旧に当てた、新しいファイルを書き出せます
  （元の文字コード・区切り・改行・引用符・行の順番を保ちます）。
・大きさ・本数を問いません。CSV 10GB × 2 本のキー照合が約 21 秒、
  テキスト 10GB × 2 本の比較が約 21 秒（MacBook Air M4 での実測）。
  1 万本のフォルダーどうしも数秒で比べます。
・「uvd 旧 新 -open」と打てば、比べ終えた結果がそのまま画面で開きます
  （画面は比べ直しません）。

■ インストール
------------------------------------------------------------------------------
1. zip を好きなフォルダーに展開します（インストーラーはありません）。
2. UwDiff.exe を起動します。
   ※ 署名していないため、初回は Windows の SmartScreen が警告を出すことが
     あります。「詳細情報」→「実行」で起動できます。
3. コマンドで使うときは、画面のメニュー「ヘルプ → コマンドライン設定…」で
   「使えるようにする」を押すと、コマンドプロンプトや PowerShell で uvd と
   打てるようになります（ユーザーの PATH に追加。管理者権限は不要）。

------------------------------------------------------------------------------
■ アンインストール
------------------------------------------------------------------------------
1. uvd を PATH に登録した場合は、「ヘルプ → コマンドライン設定…」で
   「解除する」を押します。
2. 展開したフォルダーを削除します。
3. 設定（画面の言語）を消す場合は、%APPDATA%\UwDiff フォルダーを削除します。
uvd の PATH 登録（1. で解除）のほかに、レジストリは使っていません。

■ 使い方（最初の 5 つ）
------------------------------------------------------------------------------
  uvd 旧.log 新.log -open                 テキストを比べて、画面で見る
  uvd 旧.csv 新.csv -key 点名 -o 差分.csv  表をキー列で照合して、差分を書く
  uvd 旧.log.gz 新.log.zst -o 差分.diff    圧縮のまま比べる（diff -u と同じ形）
  uvd 納品_前回 納品_今回 -o 一覧.csv      フォルダーどうしを比べる
  uvd apply 旧.csv 新.csv 採る差分.csv -o 結果.csv
                                          採った変更だけを旧に当てる

・終了コードは diff と同じです（0 = 同じ・1 = 違いあり・2 = エラー）。
・フォルダーの比較で、比べるファイルを選ぶ（-include）・外す（-exclude）の
  書き方は uvf と同じです（例 -include "**/*.{csv,log}" -exclude ".git,*.tmp"）。
・引用符は、コマンドプロンプト（cmd）では "…"、PowerShell では '…' を使います。
・日本語のファイル名を使うときは、最初に次を打ちます。
    コマンドプロンプト : chcp 65001
    PowerShell         : [Console]::OutputEncoding = [Text.Encoding]::UTF8
・画面は、ファイルを 2 つドラッグ＆ドロップすると旧・新に入ります。
  メニュー「ファイル → コマンドライン…」（Ctrl＋Shift＋K）から、uvd と同じ
  書き方で比べることもできます。
・画面の言語は、日本語と English を切り替えられます（右上の欄・設定…）。

詳しい使い方は、同梱の「UwDiff_Manual_ja.pdf」と、次のマニュアルを
ご覧ください。
  操作マニュアル（日本語）
    https://github.com/amru195704/UwDiff/blob/main/docs/manual.ja.md
  User manual (English)
    https://github.com/amru195704/UwDiff/blob/main/docs/manual.en.md

■ 既知の制限
------------------------------------------------------------------------------
・表の 1 行（引用符の中の改行を含む）は 4MB までです。
・行の順番がばらばらな巨大な表は、使うメモリが多くなります（10GB × 2 本で
  約 11GB）。メモリが足りないときは一時ファイルへ逃がして続けます（-mem で
  上限を指定できます。遅くなります）。
・Word・Excel・PDF は、取り出した文字の比較です（書式・図・数式は比べません）。
  古い形式の .doc・.xls、パスワード付きの文書、文字の無い PDF は読めません。
・Excel のシートの照合と、順番を問わない比較は、差分の一覧までです
  （採った変更の反映はできません）。
・コマンドの出力（要約・エラー）は日本語です。
